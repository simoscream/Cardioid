Projet Cardioid • Arithmétique Modulaire

Manuel & Générateur CLI Interactif

Configurez vos figures géométriques et animations d'arithmétique modulaire avec incrustation du titre d'identification et nommage explicite des frames.

⚙️ Configuration des Paramètres
⚡ Commande Générée en Temps Réel
python3 main.py --table 2 --modulo 100
Description du résultat
  • Format : PNG (800x800 px)
  • Titre incrusté : "Table 2 | Modulo 100" (Bas Droite)
  • Destination : output/images/image_table_2_modulo_100.png
💡 Collez cette commande dans votre terminal à la racine du projet Cardioid pour lancer l'exécution.

📋 Exemples Prêts à l'Emploi

1. Cardioïde Classique avec Titre
Forme de cœur (Table 2, Modulo 100) avec incrustation du titre "Table 2 | Modulo 100".
python3 main.py --table 2 --modulo 100
2. Titre en Bas à Gauche
Place le titre explicite en bas à gauche de l'image au lieu du bas à droite.
python3 main.py --table 3 --modulo 200 --title-position left
3. Néphroïde Vectorielle SVG
Génère une figure à 2 lobes au format SVG vectoriel avec titre.
python3 main.py --table 3 --modulo 200 --format svg
4. Animation Vidéo MP4 (Frames Explicites)
Génère 161 frames PNG (chacune nommée frame_XXXX_tX_m200.png avec titre incrusté) et la vidéo.
python3 main.py --video --start-table 2.0 --end-table 10.0 --step 0.05 --modulo 200
5. Vidéo MP4 avec Numérotation & Titre
Animation complète avec numéros tous les 5 points et titre d'identification.
python3 main.py --video --start-table 2.0 --end-table 5.0 --step 0.05 --modulo 100 --show-labels --label-step 5
6. Exécution des Tests Pytest
Exécute la suite complète des 11 tests unitaires.
pytest -v tests/

📖 Référence des Options CLI (main.py)

Option CLI Type Par Défaut Description & Comportement
-t, --table float 2.0 Table de multiplication (multiplicateur $n$).
-m, --modulo int 100 Nombre de points $m$ sur le cercle extérieur.
-f, --format png | svg png Format de fichier pour le rendu unitaire (`png` ou `svg`).
--hide-title flag false Masque le titre d'identification (par défaut affiché en bas à droite).
--title-position right | left right Position du titre incrusté (`right` pour bas droite, `left` pour bas gauche).
--show-labels flag false Affiche la numérotation des points le long du cercle.
--label-step int 5 Intervalle d'affichage des numéros (ex: `5` affichera 0, 5, 10, 15...).
--series flag false Génère une série de frames PNG nommées `frame_XXXX_tN_mM.png`.
--video flag false Compile les frames PNG en une vidéo MP4 avec FFmpeg.
