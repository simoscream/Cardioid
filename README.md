# Cardioid — Geometric Visualizer & Modular Arithmetic Engine

A modern, high-performance web and CLI application for exploring, rendering, and animating geometric figures generated by modular multiplication tables.

## 🌟 Key Features

1. **Interactive Real-Time Web Application (HTML5 Canvas 2D)**:
   - 60 FPS real-time smooth animation with dynamic table multiplier increment.
   - 🌐 **Multi-Language Support (7 Languages)**: English (Default), French, Spanish, German, Arabic (with RTL support), Japanese, and Chinese.
   - Dynamic table upper bound tied to current modulo $m$.
   - Full color customization (Background, Circle, Chords, Points, Text) and transparency controls.
   - Instant 1-click exports for **PNG (HD)** and **SVG (Vectorial W3C)**.
   - Built-in video recorder with format selector: **MP4 (H.264)** or **WebM (VP9)**.

2. **High-Performance Python CLI Engine**:
   - High-resolution raster rendering (Pillow) and vector rendering (SVG).
   - Identification title overlay (`Table N | Modulo M`) with position customization (bottom right / bottom left).
   - Explicit parameter-rich frame sequence generator.
   - MP4 Video Compiler with seamless FFmpeg integration.

3. **Interactive CLI Manual & Command Generator**:
   - Live visual command builder with 1-click copy buttons (`docs/manual.html`).

## 🚀 Quick Start

### 🌐 1. Web Application (GitHub Pages)
Launch the interactive web app online directly at:  
👉 **[https://simoscream.github.io/Cardioid/](https://simoscream.github.io/Cardioid/)**

Or open [web/index.html](web/index.html) in any modern browser locally.

### 🐍 2. Python CLI Engine

```bash
# Generate a single PNG image
python3 main.py --table 2 --modulo 100

# Generate a vector SVG figure with point labels every 5 points
python3 main.py --table 3 --modulo 200 --format svg --show-labels --label-step 5

# Generate a complete MP4 animation video (FFmpeg)
python3 main.py --video --start-table 2.0 --end-table 61.0 --step 0.5 --modulo 540
```
